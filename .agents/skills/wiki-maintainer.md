# Wiki Maintainer Skill

Use this skill when maintaining a Markdown-first technical wiki for a configured target set.

## Steps

1. Read `AGENTS.md`.
2. Read `.agents/workflows/wiki-lookup-and-update.md`.
3. Read `.agents/policies/wiki-update-policy.md`.
4. Read `.agents/policies/wiki-organization-policy.md`.
5. Read `.agents/policies/document-material-policy.md` when user-supplied document materials are involved.
6. Read `.agents/policies/source-and-citation-policy.md`.
7. Read `.agents/policies/repository-workspace-policy.md`.
8. Check `config/target-set.yml`.
9. Search `wiki/` before researching external sources.
10. Clone or sync target repositories under `repositories/<repository-name>/` only when source inspection is required.
11. Cite local checkout evidence with the inspected path, ref, and commit SHA.
12. Cite document material evidence with path, archive member, checksum when feasible, and ingestion date.
13. Update the smallest relevant wiki page when durable sourced knowledge should be preserved.
14. Maintain `wiki/index.md`, area indexes, `wiki/overview.md`, and `wiki/log.md` when the update affects navigation, synthesis, or durable history.
15. Verify the wiki remains human-readable.
