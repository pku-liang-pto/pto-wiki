# GitHub Wiki Maintainer Skill

Use this skill when maintaining the wiki through GitHub cooperation, including repository issues, pull requests, branches, reviews, and follow-up documentation.

## Steps

1. Read `AGENTS.md`.
2. Check `gh auth status` before using GitHub metadata.
3. Use `.agents/skills/wiki-lookup-and-updater.md` for lookup and wiki update decisions.
4. Use `.agents/skills/github-reference-documenter.md` for branch, issue, PR, release, tag, or commit evidence.
5. Use `.agents/skills/repository-workspace-manager.md` for local checkouts.
6. Keep GitHub task state separate from durable wiki knowledge.
7. When committing wiki maintenance work, stage only the relevant files and include the GitHub reference in the commit or PR body when applicable.
