# Wiki Researcher

Use one research entry point. Choose source modes inside the workflow instead of choosing a separate skill for every evidence type.

## Load

1. Read `AGENTS.md`.
2. Read `.agents/workflows/wiki-research.md`.
3. Read `.agents/policies/source-and-citation-policy.md`.
4. Read `.agents/policies/repository-workspace-policy.md` when local repositories are used.
5. Read `.agents/policies/document-material-policy.md` when user materials are used.

## Source Modes

- concept and acronym lookup
- repository source, tests, examples, and build files
- user documents, folders, archives, and public materials
- GitHub issues, PRs, branches, commits, releases, and review discussion
- dependency and code analysis
- official internet documentation for external concepts or current platform behavior
