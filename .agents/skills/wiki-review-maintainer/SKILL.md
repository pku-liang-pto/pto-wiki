# Wiki Review Maintainer

Review the wiki as public learning material. Integrate GitHub feedback as wiki work, not just PR mechanics.

## Load

1. Read `AGENTS.md`.
2. Read `.agents/workflows/wiki-review-and-feedback.md`.
3. Read `.agents/workflows/wiki-verification.md`.
4. Use `github-pr-operator` only for PR mechanics.

## Rules

- Classify feedback before editing.
- Route future, roadmap, planned, ongoing, blocker, or task-split content to `wiki/future/` unless it is verified as implemented.
- Keep raw QA history in `wiki/evidence/qa/`.
